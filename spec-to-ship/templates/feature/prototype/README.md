# Prototype

Put the built, self-contained `index.html` here (all styles, fonts and data inline, no external requests), so it works from disk and on the hosted library. Keep its source and build step next to it if it has one.

- Routes for spec state links: `#/<route>`; a route other than the start page should open the state directly.
- No real data: sample data only.
- People open it in the viewer; coding agents never read it. Whatever an agent needs goes into the spec.
- UI copy should use the keys in `../copy/` once they exist.
